# 데모 영상 샷 리스트

길이 약 75초. Pleos Connect Emulator를 Cold boot로 띄운 뒤 앱을 설치하고, Virtual Console로 기어와 차량 상태를 바꿉니다. 앱은 주행 중 사용을 선언하지 않으므로, 기어가 D이면 점검 카드를 열지 않고 시스템이 주행 중 화면을 제한할 수 있습니다.

준비:

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n io.github.kwn00.parkandleave/.MainActivity
adb forward tcp:8088 tcp:8088
```

브라우저에서 `http://127.0.0.1:8088/` 을 엽니다. 촬영 전에 창문을 조금 열고, 독서등 또는 미등을 켭니다. 타이어 공기압, 워셔액, 연료 잔량은 콘솔에 조작 항목이 없어 이 시연에 나오지 않습니다.

| 초 | 화면 | 조작 |
|---|---|---|
| 0–8 | 앱이 켜진 넓은 화면. 헤더는 Park & Leave. | 앱이 요약 화면에 있는지 확인합니다. |
| 8–20 | 점검 카드가 없습니다. 문구는 "기어를 P에 두면 점검을 시작합니다"이거나, 주행 제한이 켜지면 "주행 중에는 점검을 멈춥니다"입니다. | Virtual Console에서 Gear를 D로 바꿉니다. |
| 20–35 | "점검 중"을 거쳐 확인 카드가 나타납니다. 카드는 4열 한 칸 크기로 왼쪽부터 놓이고, 다섯 장째부터 다음 줄입니다. 카드 아래 정상으로 확인된 항목은 내용 높이만큼입니다. | Gear를 P로 바꿉니다. |
| 35–55 | 조치한 항목은 "해결됨" 카드로 남고, 남은 항목만 확인 건수에 남습니다. | 연 창문을 닫고, 켜 둔 등을 끕니다. 한 번에 하나씩 바꿉니다. |
| 55–70 | 에뮬레이터에서는 헤드라인이 "확인된 이상 없음"이고, 아래에 "확인할 수 없는 항목: 경고등, 워셔액, 주행 거리" 한 줄이 남습니다. 에뮬레이터가 워셔액과 트립 거리 값을 주지 않고, 경고등은 이 앱 권한으로 읽을 수 없기 때문입니다. 모든 신호를 읽는 차량에서는 "모두 정상", 그 아래 "내려도 됩니다"가 나옵니다. SOC가 있는 차량이면 연료는 그 줄에 없습니다. | 남은 확인 항목이 없도록 Virtual Console 값을 정상으로 둡니다. |
| 70–85 | 같은 내용이 야간 색으로 보입니다. | 에뮬레이터 디스플레이를 다크 테마로 바꿉니다. 앱은 시스템 야간 모드를 따릅니다. |

Virtual Console에서 값을 바꾼 뒤 카드가 바로 바뀌지 않으면 앱을 한 번 내리고 기어를 D로 두었다가 다시 P로 넣습니다. P에 다시 들어가면 차량 상태를 다시 읽습니다.
